魅族MX4安装Ubuntu Touch系统

魅族MX4安装Ubuntu Touch系统

作者无意间浏览网页发现了Ubuntu Touch系统，正好手边有一个魅族MX4（2+16），于是决定把它刷成Ubuntu Touch，废话不多说，我们开始吧。

这里是官网，大家可以在上面查看是否支持自己的手机。Ubuntu Touch刷机工具可以在官网Get Ubuntu Touch下载，现已支持windows,linux和mac。系统其他的工具和文件从一位大佬那里下载 https://pan.baidu.com/s/1cRAOdJtKO_UrWLPOJlNR9g 提取码：nrtu。

1、系统降级

先降到4.5.7A，再降级到4.2.8.2A

  1. 将固件放到手机根目录
  2. 关机→同时按电源键和音量加键，进入Rec模式
  3. 勾选"系统更新"，同时勾选"清除数据"，点击"开始"进行系统升级
  4. 系统升级完成后，手机自动重启
  5. 系统设置→查看系统版本

2、获取ROOT权限

官方账号解锁已经无法连接服务器了，只能用kingoroot（电脑版）获取ROOT，只不过ROOT是临时的，重启后会失效。


3、解BL,刷入第三方Rec

安装"MX4降级解锁"中mx4 bl解锁.apk，一键解锁，同时会刷入第三方recovery，上一步需要获取ROOT权限。

4、重新调整磁盘分区

进入ADB工具，打开cmd（管理员），连接手机（Rec模式下）

（有些情况下输入parted报错请更换ADB工具，检查ADB驱动，或者是手机的问题）

完成后在rec中格式分区为ext4格式（ADB shell中只支持ext2)格式化cache，system，data，data要选格式化包括内置储存的一项。

完成后打开分区表确认格式。

5、刷入Ubuntu touch

建议在晚上弄，半夜网络状态比较好。

  1. 选择手机型号
  2. 选择版本
  3. 手动音量+和电源键进入Recovery
  4. 识别设备之后下载文件并自动将文件发送至手机
  5. Ubuntu Touch开始安装，差不多20分钟手机启动
  6. 开机,进入系统



6、刷回第三方Rec

手机刷入Ubuntu Touch完成后可刷回第三方的Rec，不会影响系统启动，打开Fastboot工具，连接手机（Fastboot模式）


7、注意事项

本工具最好放置在英文路径下，如果运行出错请把本工具下的adb.exe、AdbWinApi.dll、AdbWinUsbApi.dll、fastboot.exe文件拷贝到C:\Windows\System32文件夹内。"魅族手机综合工具箱2——双击我启动.bat"为执行程序，请勿修改名字。请不要随便修改工具箱内任何文件夹下的文件和文件夹名！！！(除了x文件夹里面的)请勿修改任何内置文件的文件名，否则会出错。

MX4和魅蓝禁止使用修改分辨率的选项,仅限MX4Pro可以使用！MX4解锁存在一定风险，本人的手机已经测试过4.2.8.2和4.5.7的解锁选项不存在问题，只要不用错解锁的选项并且不乱改工具箱里的文件就不会导致变砖。请勿尝试在flyme5进行任何解锁操作！请勿尝试在flyme4.5.7.1进行任何解锁操作！

第三方REC禁止直接刷入官方固件，会直接变砖，并且fastboot也被锁上导致无法再次进行rec刷写MX4请勿使用低于4.2.8.2的固件进行解锁，会直接变砖！（作者本人吃了这个亏，刷废了一块主板）
